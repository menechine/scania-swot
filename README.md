# Atlas Copco × Scania Brasil — SWOT App

## Como publicar no GitHub Pages

1. Crie um repositório no GitHub (ex: `scania-swot`)
2. Faça upload dos arquivos deste ZIP
3. Vá em **Settings → Pages → Source → main → / (root)**
4. Acesse: `https://SEU-USUARIO.github.io/scania-swot`

## Funcionalidades
- SWOT por fábrica: Chassis, Cabinas, Transmissões, Motores
- SWOT SLA Geral
- Adicionar itens personalizados (Chassis > Forças)
- Tarefas e notas por item
- Export Excel e CSV
